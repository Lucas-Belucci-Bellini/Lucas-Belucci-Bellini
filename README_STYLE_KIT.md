# README Style Kit

Este diretório contém uma versão reutilizável da estética técnica restaurada do perfil: banners escuros, acentos dourados, títulos animados, badges, Arsenal de tecnologias, tabela de missões e footer visual.

## Comece aqui

Leia [`STYLE_TUTORIAL.md`](STYLE_TUTORIAL.md). Ele explica como copiar o template, substituir placeholders, escolher linguagens e ferramentas, personalizar cores, testar links e evitar a exposição de tokens ou dados privados.

## Estrutura visual

O kit é organizado em cinco movimentos: identidade, build log, Arsenal, missões e contato. A paleta-base é violeta profundo (`#0e0c16`/`#2b1d3b`), ouro (`#d4a24e`/`#e8c07a`), verde de estado (`#3ddc84`) e texto claro (`#f4ecdd`). Os serviços externos usados nos exemplos são `capsule-render`, `readme-typing-svg`, `skillicons.dev`, `shields.io` e `komarev`.

> Use somente tecnologias, projetos e links que representem seu próprio trabalho. O template é visual; ele não autoriza a publicação de informações privadas nem substitui a documentação do seu projeto.
